# GymPassJUST — التشغيل والشرح

فك ضغط الحزمة، افتح مجلد GymPassJUST، ثم شغّل Start-GymPass.cmd وخلي النافذة مفتوحة. افتح http://localhost:3000. تحتاج Node.js 24. بديل Docker: افتح Docker Desktop ثم شغّل docker compose up --build -d من مجلد المشروع، بعد إيقاف أي تشغيل آخر على المنفذ3000.

## الحسابات

ملف accounts/initial-accounts.md فيه حسابات طالبين ومدرب ومدير. ملف JSON المجاور يجهّز نفس كلمات المرور عند أول تشغيل. الأدوار المتاحة: طالب ومدرب ومدير فقط؛ الأمن والاستقبال غير متاحين. كلمات المرور في SQLite تكون hash، والبيانات محفوظة في data/gympass.db. مع Docker تكون في volume دائم. التشغيل المحلي وDocker لهما بيانات منفصلة، فلا تنتقل بيانات أحدهما للآخر تلقائياً.

حسابات المشروع مستقلة عن أنظمة الجامعة؛ الإيميلات المحلية معرّفات دخول وليست صناديق بريد. التسجيل الجديد يحفظ حساب طالب فعلياً، لكن لا يوجد إرسال إيميل أو تحقق بريدي. الدفع محاكاة. حفظ اللغة عربي/English لا يغيّر الحسابات أو بيانات النماذج.

## قاعدة QR النهائية

1. الطالب يشترك بباقة ويحجز حصة ثم يفتح «بطاقة الاشتراك».
2. المدرب يفتح «فحص QR وتسجيل الحضور» ويختار حصته.
3. يمسح QR الطالب بالكاميرا؛ في العرض على جهاز واحد يمكن نسخ نص الرمز ولصقه.
4. الخادم يفحص أن المدرب صاحب الحصة، وأنها بدأت ولم تنته، وأن الرمز صحيح وصالح، وأن الطالب مشترك بباقة مناسبة وعنده حجز مؤكد بنفس الحصة.
5. إذا أي شرط ناقص تظهر رسالة خطأ، ولا يتغير الحضور. إذا الشروط كلها صحيحة يتسجل الحضور تلقائياً.

المسح متاح طول الحصة، وليس أول عشر دقائق فقط. الطالب المحجوز الذي لا يُمسح رمزه يُحسب غائباً بعد نهاية الحصة في أول دورة للمهمة التي تعمل كل دقيقة. المسح المكرر يظهر «مسجل مسبقاً» ولا يكرر الحضور. لا يوجد زر حضور يدوي، ولا إيقاف سبعة أيام آلي في هذه النسخة.

QR صالح لدقيقتين كاملتين ويتجدد كل 30 ثانية وعند الرجوع للتبويب. القارئ يستخدم BarcodeDetector أو jsQR المحلي كبديل؛ لا تُرسل الصورة لطرف خارجي. الكاميرا تحتاج سماح المستخدم ومتصفحاً يدعمها على localhost أو HTTPS. إذا لم توجد كاميرا، استخدم نص الرمز في العرض. تجربة أجهزة الكاميرا الفعلية ما زالت من فحوص التسليم الميداني.

## الباقات والحجز

الباقة الفعالة أو المحجوزة للمستقبل تظهر «مشترك فيها» وزرها معطل، والخادم يمنع شراءها مرة ثانية حتى انتهائها. يمكن شراء باقة مختلفة. الحجز يفتح قبل الحصة بـ48 ساعة، والإلغاء حتى قبلها بساعتين. عند امتلاء المقاعد توجد قائمة انتظار FIFO.

## التقارير

ابدأوا بـdocs/Discussion_Summary.pdf وdocs/شرح_المشروع_للأربعة.md. التقارير الإنجليزية مبسطة ومحدثة بالقواعد أعلاه. مخططات النسخة الحالية داخل docs/diagrams. أسماء الفريق في team.json؛ راجعوا الإملاء وأكملوا الأرقام الجامعية والمساهمات الحقيقية.

npm test يشغل اختبارات القواعد والحسابات والحضور واللغة وفك QR. npm run test:load يفحص ضغط الحجز. npm run backup يفحص النسخ والاستعادة. الأدلة داخل evidence. محرك Docker لم يكن متاحاً لتشغيل الحاوية؛ الاستضافة وSSO الرسمي والمراجعات المستقلة وتجربة المستخدمين والقبول النهائي أعمال متبقية موضحة بالتقارير.
